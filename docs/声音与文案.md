# 声音与文案

> 氛寸的文案规范。例句均摘自仓库真实文案并注明出处；改任何用户可见的文字之前，先读它。

## 一句定位

**氛寸的声音，是一位懂香水的朋友**：判断笃定、语气克制、永远给退路、绝不谄媚（`src/app/api/explain/route.ts` SYSTEM 提示原文：「语气克制、温暖、不谄媚、不堆砌形容词。2~4 句话，像对朋友说话。」）。品牌句只有一句：**让每一瓶香，都用在它最好的那一刻**。

朋友的意思是：他会直说「今天不太建议用这瓶」，再告诉你硬要用怎么把影响降到最低。他记得你上次说「太冲了」，下次默认帮你少喷半下。你不听他的，他也不追问，只围着你的选择重新出主意。

## 绝不说 / 永远这样说

| 绝不说 | 永远这样说 |
|---|---|
| 社群腔与客服腔（「宝子」「亲~」「家人们」），感叹号堆叠 | 像对朋友说话，2~4 句成段 |
| emoji——产品文案 emoji 数量为零 | 用词本身带温度：「明天见」「一句就够」 |
| 无法验证的精确数字（「留香 6.2 小时」）——LLM 输出出现没给过的数字，整段退模板（route.ts） | 体感替代数字：留香说「大半个白天」，距离说「一臂之内」，喷量说「2–3 下」（format.ts / usage.ts） |
| 否定用户的选择，「其实我更推荐」 | 顺势服务：换瓶后卡片标题变「你选了 · Your Pick」，围绕新选择重算建议 |
| 把该劝退的圆成可用——avoid 回复不含否定语义时代码强制回退模板（route.ts） | 先直说后补救：「说实话，今天不太建议用……你要是今天就想用它，就……把存在感压到最低」 |
| 命令式恐吓（「千万别」「你必须」） | 后果描述 + 出路：「空间偏封闭、人也多，这瓶气场较大——建议只喷 1 下，或换一瓶更贴肤的。」（usage.ts） |
| 出错时甩锅或吓人 | 先安数据的心：「你的香柜与全部反馈都存在本机浏览器里，没有丢。」（error.tsx） |

## 体感语言对照表

档位与话术在 `src/lib/format.ts` 一一对应，写文案不得另造叫法。

**留香四段**（社区 longevity 均值 → 话术，永不给小时数）：

| 档 | 完整话术（`durationHint`） | 速览（`durationShort`） |
|---|---|---|
| < 2 | 散得偏快，出门前喷。过几个小时你自己可能先闻不到——鼻子对一直闻着的味道会变钝，别人不一定同步；真想补，半下就够 | 散得快 |
| 2–3 | 撑得住大半个白天，傍晚有正式场合值得补一次 | 大半个白天 |
| 3–4 | 基本能陪你过完这一天的白天 | 一整个白天 |
| ≥ 4 | 留得住，晚上多半还在——少喷一点就够 | 可能到夜晚 |
| 无数据 | 留香表现因人而异，用两次你就知道它在你身上能撑多久 | 因人而异 |

话术不用「约半天」这类说法——「约」字暗示背后有过一次测量。一律纯定性描述，再补一个可执行动作，让信息量落在「你该怎么办」上。依据见 [领域规则手册 §2.3](领域规则手册.md)。

手动录入的香没有社区数据，留香话术自动落「因人而异」（ManualAdd.tsx）。

**社交距离四档**（sillage tier → 三套一致口径）：

| 档 | 完整（`DISTANCE_LABEL`） | 速览（`SILLAGE_WORD`） | 副标签（`DISTANCE_SUB`） |
|---|---|---|---|
| 1 | 贴身可闻 | 贴肤 | 密闭也安全 |
| 2 | 一臂之内 | 一臂 | 日常安全 |
| 3 | 一桌之间 | 一桌 | 注意场合 |
| 4 | 整间屋都是它 | 满室 | 密闭慎用 |

**喷量**：一律「N 下」句式——`2 下` 或区间 `1–2 下`（usage.ts），不用「喷次」「泵」，不用毫升。

## 文案范例

下面都是线上正在跑的原文，各示范一条原则：

1. **「今天，刚好吗」**（FeedbackBar.tsx）—— 四个字完成一次提问。
2. **「记下了——不过今天这天气本来就吃留香，这笔算天气的，不扣它的分。」**（FeedbackBar.tsx）—— 把归因逻辑说成日常语言。
3. **「报上香名，请它入柜 →」**（EmptyShelf.tsx）—— 把一个动作写出了待客感。
4. **「可能是网络波动。你香柜里的 N 瓶香水都还在，没有丢——点下面重试就能恢复今日推荐。」**（page.tsx）—— 故障文案先报平安，再给动作。
5. **「这天没有记录。无香的日子，也是分寸。」**（journal/page.tsx）—— 对留白不加谴责。
6. **「没搜到。试试英文名或品牌名——有些香水的中文昵称和官方名差得很远。」**（SearchAdd.tsx）—— 给用户台阶，而不是甩一句「无结果」。
7. **「这句没读懂。换个说法试试，或直接点上面的场合。」**（SceneInput.tsx）—— 把没读懂算在自己头上，还附上一条退路。
8. **「出了点问题，这不是你的错」**（error.tsx）—— 先处理用户的自责。

## 反馈提问的克制原则

氛寸问得极省（FeedbackBar.tsx）：

- **一次一题**：只有「今天，刚好吗」，四个选项点一下即完成，没有第二屏。
- **每瓶每天一次**：当日去重，答过即收起，刷新也不再问。
- **答完只说一句确认**：说完即止，不追问、不弹评分、不求好评。
- **归因如实**：闷热天的「淡了点」记为环境因素，确认语明说「这笔算天气的，不扣它的分」。

写新文案的自检三问：这句话有没有一个可执行的判断？数字是不是档位或真给过的事实？用户不听的时候，还给没给他留台阶？
